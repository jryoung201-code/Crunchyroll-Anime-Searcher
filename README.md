# Crunchyroll Anime Searcher

A modern anime discovery interface with advanced search and filtering.

## Planned filters
- Title / keyword search
- Genres and excluded genres
- Minimum age rating
- Sub / Dub
- TV / Movie / OVA / Special
- Release year and season
- Rating
- Episode count
- Airing / finished
- Popularity / newest sorting
- Region availability
- Direct Crunchyroll links

## Development
Open `index.html` directly for the static prototype. The data layer is intentionally separated so a live API can be added later.
